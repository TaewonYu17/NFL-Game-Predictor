# Updated NFL Game Predictor

This project provides tools and scripts for scraping, analyzing, and predicting NFL and Premier League games using Python. It includes web scrapers, data files, and notebooks for data analysis and prediction.

## Contents
- `nfl_game_predictor.ipynb`: Main notebook for NFL game prediction.
- `nfl_schedule_results_2019_2023.csv`: NFL schedule and results data (2019-2023).
- `nfl_schedule_stats_2020_2025.csv`: NFL schedule and stats data (2020-2025).
- `nfl_webscraper.ipynb`: Notebook for scraping NFL data.
- `premier_league_webscraper.ipynb`: Notebook for scraping Premier League data.
- `elo_calculator.py`: Elo rating calculation script.
- `epl_schedule_results_2019_2023.csv`: Premier League schedule and results data.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the notebooks or scripts as needed.

## Requirements
- Python 3.8+
- See `requirements.txt` for Python package dependencies.

## Usage
- Use the provided notebooks to scrape data and perform predictions.
- Data files are generated and updated by the web scrapers.
